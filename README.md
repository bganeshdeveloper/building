# Property landing page
Deploy the contents of dist/ to any static web host. No build step required.

## Editing
- dist/config.js: brand, project name, recipient email, tagline.
- dist/index.html: project copy, location, hero text and reference statistics.
- dist/app.js: residence prices, floor plan filenames, amenities and enquiry form fields.
- dist/styles.css: colours, typography and responsive layouts.
- dist/assets/: replace reference project images with your project assets.

## Email enquiries
All three forms POST to FormSubmit for bandaruganesh2004@gmail.com.
Submit an enquiry once, then confirm the activation email received from FormSubmit (check Spam). Resubmit after activation to verify actual delivery. reCAPTCHA remains enabled. The thank-you page appears after FormSubmit finishes processing; it is not proof that Gmail has delivered the email.
FormSubmit is an external processor. This site does not store leads in a database. Recipient email is visible in client source. No SMTP passwords are required or embedded.

## Reference content
Branding is an editable concept. Property figures, gallery and plans are reference content from puravankaracodenamefutura.com, not independently verified project commitments. Confirm all details before public marketing.

## Responsive layout
Breakpoints: 1180, 980, 700 and 360 CSS pixels, with fluid scaling above these widths. Includes mobile navigation, bottom enquiry bar, horizontally scrollable pricing, native dialogs, accessible labels and reduced-motion support.
